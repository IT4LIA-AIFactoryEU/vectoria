## Reporting a Vulnerability

Please **do not** report suspected vulnerabilities through public GitLab
issues, discussions, or chat channels.

Report them privately by email to [superc@cineca.it](mailto:superc@cineca.it).
If this channel is unavailable, use the IT4LIA support contact at
[support-it4lia@cineca.it](mailto:support-it4lia@cineca.it) and clearly mark
the message as a security report.

Include, where possible:

- a description of the issue and its potential impact;
- affected versions, deployment type, and configuration;
- reproducible steps or a proof of concept;
- suggested mitigations, if known; and
- a secure way to contact you for follow-up.

Do not include credentials, access tokens, private documents, or other
sensitive data in the report. Share sensitive evidence only through a channel
agreed with the security contact.

## What to Expect

Target acknowledgement time:

The security contact will assess the report, request further details when
needed, and keep the reporter informed about material progress.

Validated issues will be handled privately until a fix or mitigation is
available. The project will then coordinate disclosure with the reporter where
appropriate. Remediation timing and any security advisory will depend on
severity, affected deployments, and the availability of a safe fix.
